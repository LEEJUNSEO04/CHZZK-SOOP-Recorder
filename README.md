# 🎥 방송 켜지면 알아서 녹화 — CHZZK / SOOP 자동 녹화기

> **치지직(CHZZK) · SOOP 라이브 방송 자동 녹화 프로그램**

스트리머의 방송 시작을 자동으로 감지하여 녹화를 시작합니다.

**방송 감지 → 녹화 → 파일 병합 → 웹 대시보드 관리 → YouTube 업로드**

까지 한 번에 처리할 수 있도록 만든 Windows용 자동 녹화 시스템입니다.

🔥 **컴퓨터 앞에서 방송 시작을 기다릴 필요 없습니다.**

개인적으로 사용하기 위해 제작한 프로그램을 공개 배포합니다.

---

## ✨ 주요 기능

- 🟢 CHZZK 라이브 방송 자동 감지 및 녹화
- 🔵 SOOP 라이브 방송 자동 감지 및 녹화
- 📺 여러 스트리머 동시 감시
- 🌐 웹 대시보드 지원
- 🎬 FFmpeg 기반 방송 녹화
- 🔗 녹화 파일 병합 지원
- 📤 YouTube 업로드 기능 지원
- 🖼️ YouTube 썸네일 생성 기능
- 🤖 OpenAI 이미지 API를 이용한 썸네일 기능 지원
- 🗄️ MySQL / MariaDB 데이터베이스 지원
