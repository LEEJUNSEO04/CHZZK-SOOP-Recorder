# 🎥 CHZZK / SOOP 자동 녹화기

치지직(CHZZK)과 SOOP의 라이브 방송을 자동으로 감지하여 녹화하는
Windows용 자동 방송 녹화 프로그램입니다.

개인적으로 사용하기 위해 제작한 프로그램을 공개 배포합니다.

---

## ✨ 주요 기능

- 🟢 CHZZK 라이브 방송 자동 감지 및 녹화
- 🔵 SOOP 라이브 방송 자동 감지 및 녹화
- 📺 여러 스트리머 동시 감시
- 🌐 웹 대시보드 지원
- 🎬 FFmpeg 기반 방송 녹화
- 🔗 녹화 파일 병합 지원
- 📤 YouTube 업로드 기능 지원
- 🖼️ YouTube 썸네일 생성 기능
- 🤖 OpenAI 이미지 API를 이용한 썸네일 기능 지원
- 🗄️ MySQL / MariaDB 데이터베이스 지원

---

## 🖥️ 지원 환경

Windows 10 / Windows 11

프로그램 실행을 위해 다음 프로그램이 필요합니다.

- Python
- FFmpeg
- MySQL 또는 MariaDB
- Google Chrome
