CHZZK · SOOP 자동 녹화 프로그램 사용법
배포용 공개 문서

======================================================================
1. 이 프로그램은 무엇인가요?
======================================================================

CHZZK와 SOOP 방송을 주기적으로 확인하고, 방송이 시작되면 자동으로 녹화하는
Windows용 프로그램입니다.

녹화가 끝나면 영상 파일을 확인하고 하나로 합칠 수 있으며, 원하는 경우 완성된
영상을 본인의 YouTube 채널에 자동 업로드할 수도 있습니다.

지원 플랫폼

- CHZZK
- SOOP

이 문서는 개인 계정, 개인 스트리머 목록, 개인 저장 경로가 들어 있지 않은
공개 배포용 설명서입니다.


======================================================================
2. 사용하기 전에 준비할 것
======================================================================

필수

- Windows 10 또는 Windows 11 64비트
- Python 3.14
- Google Chrome 최신 버전
- MySQL 또는 MariaDB
- 충분한 저장 공간
- 안정적인 인터넷 연결

Python 패키지

배포 폴더의 install_dependencies.bat를 실행하면 필요한 패키지를 설치합니다.
설치 중 오류가 나면 Python 3.14가 설치됐는지 먼저 확인하십시오.

FFmpeg

- FFmpeg 실행 파일은 이 배포본에 들어 있지 않습니다.
- FFmpeg를 별도로 설치하고 ffmpeg 명령이 PATH에서 실행되게 설정하십시오.
- 또는 직접 받은 ffmpeg.exe를 배포 폴더의 tools 폴더에 놓으십시오.
- PowerShell에서 ffmpeg -version이 실행되면 준비된 것입니다.

SOOP 녹화를 사용할 경우

- Google Chrome이 필요합니다.
- SOOP 공식 플레이어를 사용할 수 있도록 SOOPPackage 설치가 필요할 수 있습니다.
- 처음 사용할 때는 본인의 SOOP 계정으로 직접 로그인해야 할 수 있습니다.


======================================================================
3. 처음 설치하는 방법
======================================================================

1. 배포받은 압축 파일을 원하는 폴더에 풉니다.

2. install_dependencies.bat를 실행합니다.

3. MySQL 또는 MariaDB에서 database_schema.sql을 실행해 빈 테이블을 만듭니다.

4. 본인의 DB 사용자 계정을 만들고 recorder 데이터베이스 사용 권한을 줍니다.

5. config.json의 database 항목에서 사용자 이름과 CHANGE_ME 비밀번호를
   본인 DB 계정 정보로 바꿉니다.

6. 저장 위치를 변경하고 싶으면 config.json의 paths 항목을 수정합니다.
   기본값은 배포 폴더 안의 하위 폴더를 사용합니다.

7. start_all_in_one.bat를 실행합니다.

8. 브라우저에서 다음 주소를 엽니다.

     http://127.0.0.1:8765

대시보드가 보이면 기본 실행은 완료된 것입니다.


======================================================================
4. config.json에서 설정할 내용
======================================================================

config.json은 프로그램의 기본 설정 파일입니다.
메모장이나 Visual Studio Code로 열 수 있습니다.

4-1. 저장 폴더

paths 항목에서 다음 폴더를 본인 PC에 맞게 지정합니다.

- base_dir   : 프로그램이 설치된 폴더
- temp_dir   : 녹화 중인 임시 파일을 저장할 폴더
- merged_dir : 합쳐진 영상을 임시 보관할 폴더
- logs_dir   : 실행 기록을 저장할 폴더
- failed_dir : 확인이 필요한 실패 파일을 보관할 폴더
- drive_dir  : 최종 영상과 녹화 파트를 저장할 폴더

기본 예시

  "paths": {
    "base_dir": ".",
    "temp_dir": "temp",
    "merged_dir": "merged",
    "logs_dir": "logs",
    "failed_dir": "failed",
    "drive_dir": "recordings"
  }

폴더 경로를 입력할 때는 역슬래시 두 개(\\) 또는 슬래시(/)를 사용하십시오.

4-2. 데이터베이스

database 항목에 본인이 만든 MySQL/MariaDB 정보를 입력합니다.

  "database": {
    "host": "127.0.0.1",
    "port": 3306,
    "user": "사용자이름",
    "password": "비밀번호",
    "database": "데이터베이스이름",
    "charset": "utf8mb4"
  }

DB 비밀번호가 들어 있는 config.json은 다른 사람에게 보내거나 인터넷에 올리면
안 됩니다.

4-3. YouTube 업로드를 사용하지 않을 경우

배포본은 처음부터 다음 값이 false입니다. 그대로 두면 됩니다.

  "youtube": {
    "enabled": false
  }

녹화만 사용하려면 YouTube 계정 설정을 하지 않아도 됩니다.


======================================================================
5. 프로그램 실행과 종료
======================================================================

실행

1. start_all_in_one.bat를 실행합니다.
2. 검은색 콘솔 창을 닫지 않습니다.
3. 브라우저에서 http://127.0.0.1:8765 를 엽니다.
4. 대시보드 상단에 녹화기 실행 중이라고 표시되는지 확인합니다.

종료

1. All-in-One 콘솔 창을 선택합니다.
2. Ctrl+C를 한 번 누릅니다.
3. 모든 프로그램이 종료됐다는 안내가 나올 때까지 기다립니다.

작업 관리자에서 강제로 종료하면 녹화 중인 영상의 마지막 부분이 손상될 수 있습니다.


======================================================================
6. 스트리머를 등록하는 방법
======================================================================

1. 대시보드 왼쪽 메뉴에서 "스트리머 관리"를 엽니다.
2. 스트리머 이름을 입력합니다.
3. 방송 주소를 입력합니다.
4. 화질은 특별한 이유가 없다면 best를 선택합니다.
5. 저장 또는 추가 버튼을 누릅니다.
6. 사용 상태가 ON인지 확인합니다.

CHZZK 주소 예시

  https://chzzk.naver.com/live/<채널ID>

SOOP 주소 예시

  https://play.sooplive.com/<사용자ID>

SOOP 주소 뒤에 방송 번호가 붙어 있어도 프로그램이 채널 주소를 기준으로 처리합니다.

스트리머를 잠시 녹화하지 않으려면 삭제하지 말고 OFF로 바꾸는 것이 좋습니다.
녹화 중 OFF로 바꾸면 해당 스트리머의 현재 녹화만 안전하게 종료합니다.


======================================================================
7. CHZZK 사용법
======================================================================

1. 스트리머 관리에 CHZZK 라이브 주소를 등록합니다.
2. 사용 상태를 ON으로 바꿉니다.
3. 프로그램이 일정한 간격으로 방송 상태를 확인합니다.
4. 방송이 시작되면 자동으로 녹화를 시작합니다.
5. 방송이 끝나면 녹화 파일을 확인하고 후처리합니다.

로그인이 필요한 방송이나 화질을 사용하려면 CHZZK 쿠키가 필요할 수 있습니다.

쿠키를 사용할 경우

1. 본인의 브라우저에서 CHZZK에 로그인합니다.
2. 쿠키를 Netscape 형식으로 내보냅니다.
3. 파일 이름을 chzzk_cookies.txt로 저장합니다.
4. 프로그램 폴더에 넣습니다.

쿠키 파일에는 로그인 정보가 들어 있으므로 절대로 공유하지 마십시오.


======================================================================
8. SOOP 사용법
======================================================================

1. Google Chrome을 설치합니다.
2. 필요한 경우 SOOPPackage를 설치합니다.
3. 본인의 SOOP 계정으로 직접 로그인합니다.
4. 스트리머 관리에 SOOP 채널 주소를 등록합니다.
5. 사용 상태를 ON으로 바꿉니다.

접속 테스트

- 배포 폴더에 SOOP 로그인 테스트 파일이 있다면 실행합니다.
- 이 배포본에서는 SOOP_LOGIN_TEST.cmd를 실행하면 됩니다.

SOOP 녹화 특징

- SOOP은 공식 플레이어 연결을 이용하여 방송을 녹화합니다.
- 일반적인 1시간 강제 종료 없이 방송이 끝날 때까지 연결을 유지합니다.
- 방송 도중 비밀번호 방송으로 전환되더라도 이미 열린 플레이어가 계속 재생되는
  동안에는 녹화 연결을 유지할 수 있습니다.
- 방송이 실제로 종료되거나 미디어 연결이 끝나면 안전하게 후처리합니다.

SOOP 로그인용 Chrome 프로필과 쿠키는 개인 계정 정보입니다.
프로필 폴더를 다른 사람에게 보내지 마십시오.


======================================================================
9. 특정 제목일 때만 녹화하기
======================================================================

특정 스트리머의 방송 제목에 원하는 단어가 있을 때만 녹화할 수 있습니다.

config.json의 recording 안에 title_include_rules를 추가합니다.

예시

  "title_include_rules": {
    "스트리머이름": {
      "enabled": true,
      "platform": "soop",
      "include_any": ["녹화할단어"]
    }
  }

여러 단어 중 하나만 포함돼도 녹화하려면 다음과 같이 적습니다.

  "include_any": ["첫번째단어", "두번째단어"]

동작 방법

- 지정한 단어가 제목에 있으면 녹화를 시작합니다.
- 지정한 단어가 제목에 없으면 녹화하지 않습니다.
- 녹화 도중 제목에서 단어가 사라지면 현재 영상을 안전하게 마감합니다.
- 제목을 확인하지 못했을 때는 잘못 녹화하지 않도록 시작을 보류합니다.
- 규칙은 입력한 스트리머 이름과 플랫폼에만 적용됩니다.

10. YouTube 자동 업로드 사용법 - 선택 사항
======================================================================

YouTube 업로드를 사용하지 않는다면 이 부분은 건너뛰어도 됩니다.

준비

1. Google Cloud Console에서 본인의 프로젝트를 만듭니다.
2. YouTube Data API v3를 활성화합니다.
3. OAuth 동의 화면을 설정합니다.
4. 데스크톱 앱 유형의 OAuth 클라이언트를 만듭니다.
5. 받은 파일을 client_secret.json이라는 이름으로 프로그램 폴더에 넣습니다.
6. config.json에서 youtube.enabled를 true로 설정합니다.

최초 로그인

1. 먼저 All-in-One을 실행합니다.
2. 대시보드에서 "업로더 시작"을 누릅니다.
3. 브라우저가 열리면 본인의 YouTube 계정으로 로그인하고 권한을 승인합니다.
4. 승인이 끝나면 프로그램이 인증 파일을 저장합니다.

중요

- YouTube 업로더는 All-in-One과 함께 자동 시작되지 않을 수 있습니다.
- 필요한 경우 대시보드에서 직접 "업로더 시작"을 누르십시오.
- 인증 파일과 client_secret.json은 다른 사람에게 공유하지 마십시오.
- 기본 공개 상태를 사용 전에 반드시 확인하십시오. 개인 보관 목적이면 private를
  권장합니다.


======================================================================
11. 녹화 파일은 어디에 저장되나요?
======================================================================

temp 폴더

- 현재 녹화 중인 파일과 변환 중인 임시 파일이 있습니다.
- 녹화 중에는 직접 이동하거나 삭제하지 마십시오.

drive_dir로 지정한 폴더

- 완료된 파트와 최종 영상이 저장됩니다.
- 스트리머와 날짜별 하위 폴더가 만들어질 수 있습니다.

failed 폴더

- 자동으로 처리하지 못했거나 사람이 확인해야 하는 파일이 있습니다.
- 파일이 있다는 이유만으로 삭제하지 마십시오.

logs 폴더

- 프로그램 실행 기록과 현재 상태 정보가 있습니다.
- 문제가 생겼을 때 가장 먼저 확인하는 폴더입니다.


======================================================================
12. 대시보드에서 자주 보는 상태
======================================================================

녹화 중
  현재 방송 영상을 저장하고 있습니다.

후처리 중
  녹화가 끝난 파일을 검사하거나 MP4로 변환하고 있습니다.

업로드 대기
  완성된 영상이 YouTube 업로드 순서를 기다리고 있습니다.

업로드 중
  YouTube로 파일을 보내고 있습니다.

처리 대기
  파일 전송은 끝났지만 YouTube가 영상을 처리하는 중입니다.

완료
  YouTube 처리까지 정상적으로 끝났습니다.

실패
  자동 처리가 끝나지 않았습니다. 원본 파일과 오류 내용을 확인해야 합니다.

보류 또는 준비 안 됨
  녹화가 아직 끝나지 않았거나 파일 안전성 확인이 필요한 상태입니다.


======================================================================
13. 꼭 지켜야 하는 파일 안전 규칙
======================================================================

1. 실패라고 표시된 영상을 바로 삭제하지 마십시오.

2. YouTube 업로드가 100%여도 바로 원본을 삭제하지 마십시오.
   YouTube 서버의 영상 처리까지 성공해야 최종 완료입니다.

3. temp 폴더에서 크기가 계속 늘어나는 파일은 녹화 중이므로 건드리지 마십시오.

4. 긴 영상은 YouTube가 실제로 길이 문제로 거절했을 때만 자동 분할합니다.
   오류 원인을 확인하지 않고 임의로 파일을 자르지 마십시오.

5. Recorder 리로드는 활성 녹화를 안전하게 마감하지만 영상이 두 개의 세션으로
   나뉠 수 있습니다. 가능하면 녹화가 없을 때 실행하십시오.

6. 프로그램이 종료될 때는 콘솔에서 Ctrl+C를 사용하십시오.


======================================================================
14. 문제가 생겼을 때
======================================================================

대시보드가 열리지 않아요

- start_all_in_one.bat의 콘솔 창에 오류가 있는지 확인합니다.
- 주소가 http://127.0.0.1:8765 인지 확인합니다.
- Python 경로가 올바른지 확인합니다.
- 8765 포트를 다른 프로그램이 사용 중인지 확인합니다.

방송 중인데 녹화하지 않아요

- 스트리머가 ON인지 확인합니다.
- 방송 주소가 정확한지 확인합니다.
- 제목 필터를 사용 중이면 현재 제목에 지정한 단어가 있는지 확인합니다.
- CHZZK 또는 SOOP 로그인이 필요한 방송인지 확인합니다.
- logs 폴더의 recorder.log를 확인합니다.

방송이 끝났는데 녹화 중으로 보여요

- 화면을 새로고침합니다.
- 후처리 중인 항목인지 확인합니다.
- 녹화 파일 크기가 계속 증가하는지 확인합니다.
- 방송 상태 확인에 잠시 실패하면 잘못 종료하지 않도록 녹화를 유지할 수 있습니다.

YouTube 업로드가 안 돼요

- 대시보드에서 업로더를 시작했는지 확인합니다.
- Google 계정 인증이 완료됐는지 확인합니다.
- YouTube의 최근 업로드 제한에 걸렸는지 확인합니다.
- logs 폴더의 youtube_uploader.log를 확인합니다.
- 실패 파일을 삭제하거나 같은 파일을 계속 강제 재시도하지 마십시오.

SOOP 녹화가 안 돼요

- Chrome이 설치됐는지 확인합니다.
- SOOPPackage가 필요한 환경인지 확인합니다.
- SOOP 로그인 상태를 확인합니다.
- SOOP 로그인 테스트를 실행합니다.
- 보안 프로그램이 Chrome 또는 로컬 연결을 차단하는지 확인합니다.

======================================================================
16. 배포하는 사람이 확인할 것
======================================================================

- 지원 플랫폼 안내를 CHZZK와 SOOP으로 제한합니다.
- 개인 스트리머 목록을 제거합니다.
- 개인 제목 필터를 제거합니다.
- 개인 PC 경로를 제거합니다.
- DB 주소, 사용자 이름, 비밀번호를 제거합니다.
- YouTube OAuth 파일과 인증 토큰을 제거합니다.
- CHZZK 쿠키와 SOOP 로그인 프로필을 제거합니다.
- 실제 영상, 로그, 썸네일, 상태 파일을 제거합니다.
- config.example.json에 예시 값만 넣습니다.
- Python 설치 방법과 실행 파일 경로 변경 방법을 안내합니다.
- 깨끗한 Windows 사용자 계정에서 처음부터 설치 시험을 합니다.


======================================================================
17. 가장 간단한 사용 순서
======================================================================

1. Python, Chrome, MySQL/MariaDB를 설치합니다.
2. install_dependencies.bat를 실행합니다.
3. database_schema.sql을 DB에서 실행합니다.
4. config.json에 본인의 DB 계정을 입력합니다.
5. start_all_in_one.bat를 실행합니다.
6. http://127.0.0.1:8765 에 접속합니다.
7. CHZZK 또는 SOOP 스트리머를 등록하고 ON으로 바꿉니다.
8. 녹화 상태를 대시보드에서 확인합니다.
9. YouTube 기능이 필요하면 본인 계정으로 설정한 뒤 업로더를 시작합니다.
10. 종료할 때는 콘솔에서 Ctrl+C를 누릅니다.
